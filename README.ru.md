# Fastorio

[![GitHub][img-github]][url-github]
[![Modrinth][img-modrinth]][url-modrinth]

🌐 **Язык:** [English](README.md) | [Русский](README.ru.md)

Fastorio — это модпак, специально созданный для комфортной игры с большим количеством модов при сохранении высокого FPS и минимальных лагов даже во время длительных сессий.

## Ключевые особенности

- **Оптимизация прежде всего** — тщательно настроенная конфигурация
- Производительность, ориентированная на длительные игровые сессии
- Сбалансированная нагрузка на систему
- Улучшения качества жизни без лишнего контента
- Хорошо организованные системы и настройки
- Поддержка будущих обновлений и расширений

## Установка

1. Установите совместимый лаунчер Minecraft.
2. Скачайте модпак Fastorio с выбранной платформы.
3. Импортируйте пак или создайте новый инстанс.
4. Запустите игру один раз, чтобы сгенерировать все конфигурационные файлы.
